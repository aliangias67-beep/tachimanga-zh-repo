# OClaw Tachimanga 中文扩展仓库

这是按 Tachimanga 官方仓库格式建立的 repo。

添加地址：

```text
https://raw.githubusercontent.com/aliangias67-beep/tachimanga-zh-repo/main/repo/index.min.json
```

目录结构：

```text
repo/index.min.json
repo/repo.json
repo/apk/*.apk
repo/icon/*.png
```

注意：Tachimanga 使用的是 APK 扩展包，不是 Mihon 的 JAR 文件。
